# 钟形摆动（绕导电嘴尖点）计算公式

实现：同目录上级 `bell_weave_around_tip.py`  
几何对照：`Welding/摆动/weave.html`

与常规「TCP 左右平移」不同：焊枪绕 **TCP 工具 Z+ 上一点 O**（导电嘴尖点）左右摆。O 沿焊缝前进，工具 Z 始终穿过 O。

- `D = 0`：TCP 已在尖点，只改姿态（定点倾摆）
- `D > 0`：TCP 绕尖点走圆弧，尖点位置不左右偏

下发的是当前激活 TCP 的笛卡尔位姿 `[x, y, z, rx, ry, rz]`（m / rad，Elite 轴角）。脚本不 `set_tcp`。示教起终点与运行必须用同一套 TCP。

---

## 1. 输入


| 符号                  | 含义                     | 单位                 |
| ------------------- | ---------------------- | ------------------ |
| P_0, R_0            | 起点 TCP 位置与姿态           | m，轴角 rad           |
| P_1, R_1            | 终点 TCP 位置与姿态           | m，轴角 rad           |
| D                   | 尖点相对 TCP，沿工具 Z+        | m（程序里用 mm 再除 1000） |
| \theta_\mathrm{max} | 单侧最大摆角                 | rad                |
| A                   | 可选，TCP 横向峰峰值           | m                  |
| V_w                 | 尖点沿焊缝前进速度              | m/s（程序里用 mm/s）     |
| f                   | 摆动频率                   | Hz                 |
| n_\mathrm{spc}      | 每周期采样点数                | 默认 20              |
| wave                | `triangle`（默认）或 `sine` |                    |


若给定 A 且 D>0：


\theta_\mathrm{max} = \arcsin\left(\frac{A}{2D}\right)


TCP 横向峰峰值与摆角的关系：


A_\mathrm{tcp} = 2 D \sin\theta_\mathrm{max}


---



## 2. 焊缝参数与采样

焊缝方向与长度：


\mathbf{x} = \frac{P_1 - P_0}{P_1 - P_0},\quad
L = P_1 - P_0


一个摆动周期内尖点前进距离、周期数、总段数：


p = \frac{V_w}{f},\quad
N = \mathrm{round}(L / p),\quad
n = N \cdot n_\mathrm{spc}


第 i 个点（i = 0,1,\ldots,n）：


s = L \cdot \frac{i}{n},\quad
t = \frac{s}{L}


名义 TCP（未摆动）：位置线性插值，姿态轴角 slerp。


P_\mathrm{nom}(t) = (1-t)P_0 + tP_1



R_\mathrm{nom}(t) = \mathrm{Slerp}(R_0, R_1, t)


---



## 3. 旋转中心 O

R_\mathrm{nom} 第三列是工具 \mathbf{Z}+：


\mathbf{Z}*\mathrm{tool} = R*\mathrm{nom} \mathbf{e}_z



\mathbf{O} = P_\mathrm{nom} + D \cdot \mathbf{Z}_\mathrm{tool}


起终点姿态相同时，所有 \mathbf{O} 落在同一条直线上（焊缝中心线方向）。校验见 `check_pivot_line.py`。

---



## 4. 摆角 \theta(s)

相位：


\phi = \left(\frac{s}{p}\right) \bmod 1,\quad \phi \in [0,1)


**三角波（默认）**，一个周期：中心 → 左极限 → 中心 → 右极限 → 中心：


\theta(\phi) =
\begin{cases}
4\phi\theta_\mathrm{max}, & 0 \le \phi < 0.25 
\theta_\mathrm{max} - 4(\phi-0.25)\theta_\mathrm{max}, & 0.25 \le \phi < 0.75 
-\theta_\mathrm{max} + 4(\phi-0.75)\theta_\mathrm{max}, & 0.75 \le \phi < 1
\end{cases}


**正弦：**


\theta(\phi) = \theta_\mathrm{max} \sin(2\pi\phi)


---



## 5. 绕 O、绕焊缝前进轴旋转

旋转轴为焊缝方向 \mathbf{x}，过点 \mathbf{O}：


R_\theta = \mathrm{Rot}(\mathbf{x},\theta)


TCP 位置：


P = \mathbf{O} + R_\theta (P_\mathrm{nom} - \mathbf{O})


TCP 姿态：


R = R_\theta R_\mathrm{nom}


将 R 转为 Elite 轴角 \mathbf{r}=(r_x,r_y,r_z)。相邻点选取与上一帧欧氏距离最近的轴角表示（可加减 2\pi 绕同一轴），避免 \pm\pi 跳变导致 `movep` 反向。

几何结论：

- \mathbf{O} 只沿焊缝走，不左右偏
- TCP 在过 \mathbf{O}、垂直于 \mathbf{x} 的平面内走半径 D 的圆弧
- 摆动后工具 Z 仍穿过 \mathbf{O}：P + D\cdot\mathbf{Z}(R) = \mathbf{O}

---



## 6. 脚本 `movep`

格式与焊接任务脚本一致：

```text
def a():
 movep([x, y, z, rx, ry, rz], a, v, r)
 ...
end
```

- 位姿：六元数列表，不用 `p[]`
- `end` 后不再调用函数
- a 默认 1.2\mathrm{m/s^2}
- v：TCP 折线路径长度 \ell 除以焊缝时间 L/V_w，即 v = \ell \cdot V_w / L
- 中间点交融半径约 0.35 倍最小步长（上限 1 mm），末点 r=0

生成文件默认在 `out/`：`bell_weave.csv`、`bell_weave.script`。
