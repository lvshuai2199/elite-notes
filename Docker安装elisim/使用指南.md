## 🚀 快速开始

### 最简单的启动方式
```bash
./start_elibotsim.sh
```
这将使用默认配置启动 CS66 机器人仿真环境。

### 启动指定型号的机器人
```bash
./start_elibotsim.sh -m LS65
```

### 后台运行
```bash
./start_elibotsim.sh -m CS612 -d
```

## 📖 启动参数说明

### 命令格式
```bash
./start_elibotsim.sh [选项]
```

### 参数列表

| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| `-m <model>` | 机器人型号 | CS66 | `-m LS65` |
| `-c <id>` | 控制箱 ID | 1 | `-c 2` |
| `-t <id>` | 工具类型 ID | 1 | `-t 2` |
| `-b <id>` | 总线代际 ID | 0 | `-b 1` |
| `-v <version>` | 镜像版本 | 2.16.0 | `-v 2.16.0` |
| `-p <folder>` | 程序目录（主机路径） | 自动 | `-p /home/user/programs` |
| `-u <folder>` | ELITECO 目录（主机路径） | 自动 | `-u /home/user/eliteco` |
| `-n <name>` | 容器名称 | elibotsim | `-n my_robot` |
| `-i <ip>` | 容器 IP 地址 | 192.168.56.101 | `-i 192.168.56.102` |
| `-d` | 后台运行模式 | 前台 | `-d` |
| `-f <ports>` | 自定义端口映射 | 见下文 | `-f "-p 8080:6080"` |
| `-r <0\|1\|2>` | 机器人系列标志 | 自动 | `-r 2` |
| `-R <base>` | 镜像仓库地址 | crpi-yhojs26vvyw1g1kz.cn-hangzhou.personal.cr.aliyuncs.com/dukang123/elite_robot_sim | `-R eliterobots/sim` |
| `-h` | 显示帮助信息 | - | `-h` |

### 参数详细说明

#### 1. 机器人型号 (`-m`)
指定要仿真的机器人型号，支持 CS/ES/LS 系列。详见[机器人型号支持](#机器人型号支持)。

**示例**：
```bash
./start_elibotsim.sh -m CS66    # CS 系列
./start_elibotsim.sh -m ES66    # ES 系列（等同于 CS66）
./start_elibotsim.sh -m LS65    # LS 系列
```

#### 2. 控制箱 ID (`-c`)
- `1` = CS_SERIES（标准控制箱）**[默认]**
- `2` = CS-X_SERIES（X 系列控制箱）
- `3` = CS-MINI_SERIES（Mini 系列控制箱）

**示例**：
```bash
./start_elibotsim.sh -m CS66 -c 2    # 使用 X 系列控制箱
```

#### 3. 工具类型 ID (`-t`)
- `1` = 默认工具 **[默认]**
- 其他值根据实际工具配置

**示例**：
```bash
./start_elibotsim.sh -m CS66 -t 2    # 使用工具类型 2
```

#### 4. 总线代际 ID (`-b`)
- `0` = High Speed Bus（高速总线）**[默认]**
- `1` = EtherCAT Bus（EtherCAT 总线）

**注意**：LS 系列机器人会自动使用 EtherCAT 总线（-b 1）

**示例**：
```bash
./start_elibotsim.sh -m CS66 -b 1    # 使用 EtherCAT 总线
```

#### 5. 镜像版本 (`-v`)
指定要使用的 Docker 镜像版本标签。

**示例**：
```bash
./start_elibotsim.sh -v 2.16.0-optimized
```

#### 6. 镜像仓库地址 (`-R`)
自定义 Docker 镜像仓库地址，用于从不同的镜像源拉取镜像。

**默认值**：`crpi-yhojs26vvyw1g1kz.cn-hangzhou.personal.cr.aliyuncs.com/dukang123/elite_robot_sim`

**示例**：
```bash
# 使用 Docker Hub 官方仓库
./start_elibotsim.sh -m CS66 -R eliterobots/cs-series-simulator

# 使用其他私有仓库
./start_elibotsim.sh -m CS66 -R myregistry.com/elite-sim
```

#### 7. 程序目录 (`-p`)
挂载主机上的程序目录到容器中，用于持久化存储机器人程序。

**默认路径**：`~/.elibotsim/<系列>/<型号>/programs`

**示例**：
```bash
./start_elibotsim.sh -m CS66 -p /home/user/my_programs
```

#### 8. ELITECO 目录 (`-u`)
挂载主机上的 ELITECO 配置目录到容器中。

**默认路径**：`~/.elibotsim/<系列>/eliteco`

**示例**：
```bash
./start_elibotsim.sh -m CS66 -u /home/user/my_eliteco
```

#### 9. 容器名称 (`-n`)
自定义容器名称，用于同时运行多个仿真实例。

**示例**：
```bash
./start_elibotsim.sh -m CS66 -n robot1
./start_elibotsim.sh -m LS65 -n robot2 -i 192.168.56.102
```

#### 10. 容器 IP (`-i`)
指定容器的 IP 地址，必须在 `192.168.56.1-254` 范围内。

**示例**：
```bash
./start_elibotsim.sh -i 192.168.56.102
```

#### 11. 后台运行 (`-d`)
以后台模式（detached）运行容器，不占用终端。

**示例**：
```bash
./start_elibotsim.sh -m CS66 -d
```

#### 12. 机器人系列标志 (`-r`)
- `0` = CS_SERIES
- `1` = ES_SERIES
- `2` = LS_SERIES

**注意**：通常不需要手动指定，使用 `-m` 参数会自动设置。

## 🌐 访问方式

### 1. Web 界面（推荐）
启动容器后，通过浏览器访问：

```
http://localhost:6080
```

这将打开 noVNC Web 界面，可以直接在浏览器中操作仿真环境。

### 2. SSH 连接
```bash
ssh -p 2222 root@localhost
```
**密码**：`elite`

### 3. 机器人控制端口
- **30001-30004**：机器人控制接口
- **29999**：仪表板服务器

### 默认端口映射
```
主机端口 → 容器端口
6080    → 6080   (noVNC Web 界面)
2222    → 22     (SSH)
30001   → 30001  (机器人控制)
30002   → 30002  (机器人控制)
30003   → 30003  (机器人控制)
30004   → 30004  (机器人控制)
29999   → 29999  (仪表板)
```

## 💡 常见使用场景

### 场景 1：快速测试默认机器人
```bash
./start_elibotsim.sh
```
然后访问 `http://localhost:6080`

```bash
./start_elibotsim.sh -m LS65 -p ~/my_robot_programs
```

```bash
# 启动第一个机器人（CS66）
./start_elibotsim.sh -m CS66 -n robot1 -i 192.168.56.101 -d

# 启动第二个机器人（LS65）
./start_elibotsim.sh -m LS65 -n robot2 -i 192.168.56.102 -d -f "-p 6081:6080 -p 2223:22"
```

访问：
- 机器人 1：`http://localhost:6080`
- 机器人 2：`http://localhost:6081`

### 场景 4：使用 EtherCAT 总线的 CS 系列机器人
```bash
./start_elibotsim.sh -m CS612 -b 1
```

### 场景 5：使用 X 系列控制箱
```bash
./start_elibotsim.sh -m CS66 -c 2
```

### 场景 6：完整配置示例
```bash
./start_elibotsim.sh \
  -m CS612 \
  -c 2 \
  -t 1 \
  -b 1 \
  -p ~/robot_programs \
  -u ~/robot_config \
  -n my_cs612 \
  -i 192.168.56.105 \
  -d
```

## 🛠️ 故障排查

### 问题 1：容器启动失败
**可能原因**：
- 端口已被占用
- 容器名称冲突
- IP 地址冲突

**解决方法**：
```bash
# 检查端口占用
netstat -tuln | grep 6080

# 停止并删除旧容器
docker stop elibotsim
docker rm elibotsim

# 使用不同的容器名称和 IP
./start_elibotsim.sh -n elibotsim2 -i 192.168.56.102
```

### 问题 2：Web 界面黑屏
**可能原因**：
- 仿真服务未启动
- elite_tool 版本不匹配

**解决方法**：
```bash
# 查看容器日志
docker logs elibotsim

# 进入容器检查服务状态
docker exec -it elibotsim supervisorctl status
```

### 问题 3：无法访问 Web 界面
**可能原因**：
- 端口映射错误
- 防火墙阻止

**解决方法**：
```bash
# 检查端口映射
docker port elibotsim

# 检查防火墙（Ubuntu/Debian）
sudo ufw status
sudo ufw allow 6080
```

### 问题 4：机器人型号不支持
**错误信息**：`Unknown model: XXX`

**解决方法**：
查看[机器人型号支持](#机器人型号支持)章节，确认型号是否在支持列表中。

### 问题 5：IP 地址无效
**错误信息**：`Invalid IP range: XXX`

**解决方法**：
IP 地址必须在 `192.168.56.1-254` 范围内。

```bash
./start_elibotsim.sh -i 192.168.56.101  # ✅ 正确
./start_elibotsim.sh -i 192.168.1.100   # ❌ 错误
```

## 📝 配置文件说明

### 机器人绑定配置
容器内部配置文件：`/opt/EliteRobots/EliServer/eli_robot_data/robot_bind.conf`

该文件存储了机器人的配置信息：
- `ControlBox Generation`：控制箱 ID
- `Tool Type`：工具类型 ID
- `Robot Type`：机器人类型 ID
- `Robot Generation`：机器人代际 ID
- `Robot BusType`：总线类型 ID

### 持久化存储
默认情况下，程序和配置文件存储在主机的 `~/.elibotsim/` 目录下：

```
~/.elibotsim/
├── CS_SERIES/
│   ├── eliteco/          # ELITECO 配置
│   ├── CS66/
│   │   └── programs/     # CS66 程序
│   └── CS612/
│       └── programs/     # CS612 程序
├── ES_SERIES/
│   └── ...
└── LS_SERIES/
    ├── eliteco/
    └── LS65/
        └── programs/     # LS65 程序
```

## 📚 环境变量说明

容器内部会设置以下环境变量：

| 环境变量 | 说明 | 可能的值 |
|----------|------|----------|
| `ROBOT_TYPE_ID` | 机器人类型 ID | 6206, 61052, 等 |
| `TOOL_TYPE_ID` | 工具类型 ID | 1, 2, 等 |
| `CONTROL_BOX_ID` | 控制箱 ID | 1, 2, 3 |
| `ROBOT_GENERATION_ID` | 机器人代际 ID | 0, 1, 2 |
| `ROBOT_BUS_GENERATION_ID` | 总线代际 ID | 0, 1 |
| `CONTROL_BOX_GENERATION` | 控制箱代际名称 | CS_SERIES, CS-X_SERIES, CS-MINI_SERIES |
| `ROBOT_GENERATION` | 机器人代际名称 | CS_SERIES, ES_SERIES, LS_SERIES |
| `ROBOT_BUS_GENERATION` | 总线代际名称 | HIGH_SPEED_BUS, ETHERCAT_BUS |
